📊 Análise de Dados Educacionais – ENEM + Censo Escolar 2024

Este projeto tem como objetivo realizar uma análise exploratória e descritiva dos dados do ENEM, integrando informações do Censo Escolar 2024, com foco na avaliação do desempenho das escolas e no apoio à tomada de decisão baseada em dados no contexto educacional.

Utilizando dados públicos do INEP, o projeto explora diferenças de desempenho entre municípios, tipos de escola e áreas do conhecimento, apresentando os resultados por meio de dashboards interativos no Power BI.

🎯 Objetivo do Projeto

Analisar o desempenho das escolas no ENEM

Integrar dados do ENEM com o Censo Escolar para enriquecer a análise

Identificar padrões, desigualdades e extremos de desempenho

Criar indicadores claros e visualizações que facilitem a interpretação dos dados

🗂️ Fontes de Dados

Microdados do ENEM (INEP)

Censo Escolar 2024 (INEP)

Os dados foram tratados, padronizados e integrados por meio de identificadores das escolas.

🧹 Tratamento e Preparação dos Dados

As principais etapas de preparação incluem:

Limpeza dos dados (valores ausentes e inconsistências)

Padronização de variáveis e chaves de integração

Integração entre as bases do ENEM e do Censo Escolar

Criação de métricas estatísticas descritivas
